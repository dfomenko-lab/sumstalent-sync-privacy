Privacy Policy — Sumstalent Sync

Last updated: 9 November 2026

Sumstalent Sync is a personal desktop application used only by its owner, Dmitry Fomenko (dfomenko@gmail.com), on his own computer.

What Google data it uses

With the owner's consent the application uses the Google People API (scope https://www.googleapis.com/auth/contacts) to read the owner's Google Contacts, create new contacts and add phone numbers, e-mail addresses and links to existing contacts in the owner's own account.

How data is handled

  • Data is processed only on the owner's computer. There is no server, and data is not sent to any third party.
  • The Google sign-in token is stored locally in Windows Credential Manager.
  • Google user data is not sold, not used for advertising and not used to train AI models.
  • The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
